# Outlook settings

Built-in settings applied before writing code for the same problem (settings never break).
Record the final values so they can be reapplied after an account reset.

| Setting                  | Where                              | Value                                                            |
| ------------------------ | ---------------------------------- | ---------------------------------------------------------------- |
| Keyboard shortcuts       | Settings → General → Accessibility | Gmail (confirmed on in the Oct 2026 capture)                     |
| Layout density           | Settings → General → Appearance    |                                                                  |
| Reading pane             | Settings → Mail → Layout           | "Hide" for Overlook's Fastmail and Focus layouts; right for Calm |
| Conversation view        | Settings → Mail → Layout           |                                                                  |
| Focused Inbox            | Settings → Mail → Layout           |                                                                  |
| Ribbon                   | View → Layout / ribbon menu        |                                                                  |
| Notifications and sounds | Settings → General → Notifications |                                                                  |
| Copilot / promo toggles  | (wherever the tenant allows)       |                                                                  |
